# PCB Insight

자화전자 구매팀을 가정해 가상 협력사 A–D의 납품 손익과 DeepPCB 분류 모델의 검증 성능을 비교하는 React + Vite 웹 대시보드입니다. 협력사, 납품 수량과 단가, 비용은 시연용 가정입니다.

```powershell
cd pcb-dashboard
.\start-dashboard.cmd
```

터미널에 표시된 주소를 엽니다. 실행 파일은 일반 Node.js를 먼저 찾고, 현재 터미널에 `npm`이 잡혀 있지 않으면 PyCharm에 포함된 Node.js를 확인합니다. 필요한 패키지는 처음 실행할 때 설치합니다. 이 폴더는 데이터 원본을 읽기 위해 DNN 프로젝트 바로 아래에 둡니다.

`npm`을 사용할 수 있는 터미널에서 `npm.cmd test`는 혼동행렬과 임계값 및 손익 계산을 검사하며, `npm.cmd run build`는 `dist/`에 정적 웹 파일을 생성합니다.

- 검증 정확도, Macro F1, 불량 재현율과 혼동행렬은 `results/full_scratch/full_scratch_aux_001/validation_predictions.csv`의 400개 점수에서 계산합니다. 혼동행렬의 칸을 누르면 해당 원본과 점수를 확인할 수 있습니다.
- 임계값별 검증 오탐률과 누락률을 공통 가정으로 사용합니다. 불량 판정이 나면 건당 재검사비를 반영하고, 재검사로 정상 확인된 제품은 전량 판매로 가정합니다.
- 예상 이익은 정상 판매 매출에서 매입비, 재검사비 및 누락 처리비를 차감한 값입니다. 이익률은 예상 이익을 매출로 나눈 값으로, 매출이 0이면 표시하지 않습니다.
- 납품 구성 및 비용을 편집할 수 있고, 현재 임계값과 비용 내역을 포함한 협력사별 결과를 CSV로 내보낼 수 있습니다. 새로고침하면 초기 가정으로 돌아갑니다.

개발·빌드 전에 검증 점수와 로컬에 있는 원본 사진을 `public/validation/`에 준비합니다. GitHub에서 받은 프로젝트는 저장된 검증 점수로 지표, 손익 계산과 사례 상세를 표시합니다. 사례 사진까지 표시하려면 프로젝트의 `data/`에 DeepPCB 원본을 배치하고 다시 실행하세요. 검증 점수는 고정 검증 그룹에서 측정한 값이며 운영 환경의 기대 성능은 별도로 검증해야 합니다.
